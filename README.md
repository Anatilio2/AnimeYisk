# 🎬 AnimeYisk - Galería Interactiva de Anime

**AnimeYisk** es una aplicación web creada cuando estaba aburrido , es un alista donde administro las series de anime que estoy viendo , e visto y estan pendientes por ver .

![AnimeYisk Banner](https://images.unsplash.com/photo-1607604276583-eef5d076aa5f?q=80&w=1200&auto=format&fit=crop)

    ---

## 💡 ¿Por qué hice este proyecto?

   Todo comenzó un día cualquiera en el que estaba **totalmente aburrido**. En lugar de pasar el tiempo sin hacer nada, decidí abrir el editor de código y ponerme a crear una pagina  propia para gestionar mis animes, probar animaciones  con Tailwind, conectar APIs  y  almacenamiento local e importación de datos con js . ¡Y así nació AnimeYisk!

    ---

## ✨ Características Principales

   * **Pantalla de Bienvenida :** Presentación  para ingresar a la galería.
    * **Gestión de Colección:** Búsqueda en tiempo real, filtros por estado (*Viendo*, *Completado*, *Pendiente*, *Favoritos*) y ordenación.
    * **Autocompletado con AniList:** Búsqueda automática de imágenes, géneros y calificaciones desde la API GraphQL de AniList.
    * **Modo Administrador:** Control de acceso mediante contraseña hash  para agregar, editar o eliminar entradas.
    * **Importación y Exportación:** Soporte para copias de seguridad en formato JSON con fusión inteligente de datos sin duplicados.
    * **Métricas y Estadísticas:** Panel visual con gráficos y porcentajes de avance de tu lista.
    * **Vistas Alternables:** Alterna entre vista de tarjetas (*Grid*) y vista de tabla compacta.

   ---

## 🚀 Tecnologías Utilizadas

   * **HTML5 & CSS3**
    * **[Tailwind CSS](https://tailwindcss.com/):** Estilizado responsivo y moderno.
    * **[Alpine.js](https://alpinejs.dev/):** Framework reactivo y ligero para la lógica del frontend.
    * **[SweetAlert2](https://sweetalert2.github.io/):** Modales y alertas personalizadas.
    * **[AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/):** Consulta de datos e imágenes de anime.
